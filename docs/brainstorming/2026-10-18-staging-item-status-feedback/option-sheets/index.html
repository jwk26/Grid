  4. 그 상태에서 Check again을 누르세요. 버튼은 바로 흐려지고, ?는 0.3초 동안 그대로 있다가 로더로 바뀌어야 합니다.
  5. 행 되살리기 → 실패. !와 테두리가 생기고, 행은 그대로 남습니다.

질문 BExplorer의 NEW 카드에서 복구 버튼(Check again / Retry)을 어디에 둘까

Inbox Explorer에 방금 놓은 Node·Bit 카드는 열 폭을 꽉 채우는 가로 행입니다. 행 왼쪽에 NEW 표시가 있고, 오른쪽 끝에 Undo 버튼 칸(↶)이 고정되어 있습니다. 아래는 Undo 결과를 모를 때(Node, ?)와 Undo가 실패했을 때(Bit, !)의 모습을 실제 열 폭 두 가지로 그린 것입니다. 판단은 retro-mac과 neumorphism으로 해 주세요. 이 두 테마는 앱 CSS 값을 그대로 옮긴 실제 모양입니다. griddo는 지금 Explorer에서도 정사각형 Grid 카드를 쓰는데, 최종 테마 4종(paper 포함)은 모두 가로 행이라 griddo 색으로 행을 참고용으로 그렸습니다.

이렇게 확인해 보세요
  1. 먼저 테마를 neumorphism이나 retro-mac으로 바꾸세요.
  2. 맨 위 "평소" 줄과 비교해 보세요. 문제가 생겼을 때 행 모양이 얼마나 바뀌는지가 핵심입니다.
  3. 150px 열에서 제목이 몇 글자나 남는지 보세요. 1024px 화면에서 Pool을 열면 실제로 이 폭입니다.
  4. 버튼과 행 몸통에 각각 마우스를 올리거나 Tab으로 이동해 툴팁을 보세요.
